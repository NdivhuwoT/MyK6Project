# My K6 Project

This is a K6 load testing project for API testing.

## Running Tests

To run the tests:
```
npm run test
```

## Viewing Report

After running tests, open `report.html` in your browser to view a summary report.

## Project Structure

- `Tests/`: Test scripts
- `Request/`: API request functions
- `Checks/`: Validation checks
- `Data/`: Test data payloads
- `Config/`: Configuration files
